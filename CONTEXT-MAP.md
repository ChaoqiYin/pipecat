# Contexts

This repository holds the Pipecat framework and one application built on it. They
carry separate vocabularies and separate decisions, so each has its own documents.

| Context                           | Glossary                    | Decisions                 |
| --------------------------------- | --------------------------- | ------------------------- |
| `local-voice-app/` — the browser voice application | `local-voice-app/CONTEXT.md` | `local-voice-app/docs/adr/` |

The framework itself is documented by `AGENTS.md`, `README.md` and `CONTRIBUTING.md`,
and has no glossary of its own.
